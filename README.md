# Клод-бот для Telegram

Telegram-бот, который отвечает через Claude (использует подписку Claude Code — API-ключ не нужен).

## Запуск

1. Получи токен у @BotFather в Telegram: `/newbot` → имя → юзернейм → скопируй токен.
2. Положи токен в файл `.env` (рядом с bot.js):
   ```
   BOT_TOKEN=1234567890:AAAbbbCCC...
   ```
3. Запусти двойным кликом `start.bat` (или `node bot.js` в терминале).
4. Напиши боту в личку `/start` — первый написавший становится владельцем.

## Использование

- **Личка** — бот отвечает только владельцу.
- **Группы** — добавь бота в группу, отправь там `/allow` (только владелец). После этого бот отвечает, когда его упоминают `@юзернейм_бота` или отвечают на его сообщение.
- `/deny` — перестать отвечать в группе.
- `/reset` — очистить контекст диалога в текущем чате.

## Дубль постов в VK и MAX

Пересылаешь пост из канала боту в личку — он дублирует его на другие площадки.

1. Перешли пост из @neurokean_ch боту в личку. Бот ответит: «Принял на дубль: текст N симв., 2 фото».
2. Напиши `+` — бот публикует в VK (стена сообщества) и MAX и присылает ссылки. `-` — отмена.
3. Альбом пересылай целиком: бот ждёт пару секунд и собирает все фото в один пост.

В Telegram-канал дубль не идёт: пост там уже есть.

## Рерайт чужих постов

Пересылаешь пост **из чужого канала** — бот возвращает его переписанным твоим
голосом: факты и цифры сохраняет, чужие ссылки, названия каналов и призывы
подписаться вычищает.

Дальше как с дублем: `+` — и он публикует пост **на все площадки, включая сам
Telegram-канал** (текст-то новый, в канале его ещё нет). Канал VK-Мессенджера
подхватит сторож, он смотрит на стену ВК.

`/esche` — другой вариант того же поста. Прошлый вариант при этом снимается,
так что `+` опубликует только последний.

Команда для этого не нужна: бот различает дубль и рерайт по источнику пересылки.
Короткие пересылки (меньше 150 символов) он не переписывает — их обсуждает как
обычное сообщение. Если надо продублировать что-то не из канала, перешли и сразу
напиши `/dubl`.

Команды:

- `/dubl` — взять последнюю пересылку на дубль (для источников не из канала).
- `/ochered` — последние 10 заявок и что с ними стало.
- `/text` — прислать текст последнего дубля, чтобы вставить его в канал VK-Мессенджера.
- `/crosspost_check` — проверить, живы ли токены VK и MAX с того IP, где крутится бот (ничего не публикует).
- `/crosspost_status` — что настроено, а что нет.

Настройка — переменные окружения (см. `.env.example`): `CROSSPOST_CHANNEL`,
`VK_GROUP_ID`, `VK_USER_TOKEN`, `MAX_BOT_TOKEN`, `MAX_CHAT_ID`.
На bothost.ru они заводятся в панели, локально — в `.env`.

Чего бот не умеет и не сможет:

- **Канал в VK-Мессенджере** закрыт для любых API — его постим руками через браузер.
  После публикации бот сам напомнит и отдаст текст по `/text`.
- **Видео тяжелее 20 МБ** Telegram Bot API не отдаёт — такое вложение бот пропустит
  и честно об этом напишет.
- Жирный шрифт и курсив нигде не переносятся: VK и MAX принимают плоский текст.

Тесты (реальные площадки не трогают, поднимают заглушку): `npm test`.

## Важно

- Основная копия крутится на bothost.ru — она работает всегда, компьютер для неё не нужен.
  Локальный `start.bat` — запасной запуск: **вместе с хостинговой копией его включать нельзя**,
  два процесса с одним токеном дерутся за long polling и сообщения теряются.
- У бота нет инструментов: он не читает файлы, не ходит в интернет, не видит картинки и видео — только текст.
- Контекст диалога хранится по каждому чату отдельно (state.json).
